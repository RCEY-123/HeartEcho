# 角色卡 v1 校验说明

- 19 位名单、唯一 ID、七项必填内容及每位三组原创对话检查通过。
- 使用 dev.5 最终安装包内的角色存储模块，在独立临时数据目录完成 19 张卡保存、读取及逐字段比较；同名二次导入均拒绝覆盖。
- 20 张本地参考立绘（含塔什干额外换装）文件摘要核对通过；未随公开包分发原图。
- 公开文件通过本机隐私审查：未发现已知本机私密值、用户数据文件、凭据格式或个人主目录路径。
- 未调用付费模型测试演绎，不保证不同模型完全遵循同一文风。未更改用户实际数据或替用户启用主动消息功能。

本校验针对角色卡内容与当前格式兼容性，不替代应用安装包自身的验证报告。角色卡只含设定，不附 API Key、聊天或记忆数据库。
