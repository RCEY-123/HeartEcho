# 角色卡管理（dev.18 起）

打开「角色工作室」，使用角色列表旁的「导入角色卡」「导出角色卡」「删除角色卡」。

## 导入

从 GitHub 仓库的「角色卡」目录下载原生 JSON 文件，点击导入，一次可选择多张。ZIP 请先解压再选择其中的角色 JSON，`index.json` 是目录索引，不能作为角色卡导入。导入结果逐张显示；相同 ID 会跳过，已有卡不会被静默覆盖。

导入后可直接在角色列表选中查看，无需重启或手工复制到数据目录。导入到当前实例；心语通用版、TB 版和其他实例各有独立的角色列表。

## 导出

先保存编辑，再选择要导出的角色并点击导出，得到与仓库原生格式兼容的 JSON 文件。导出包含角色设定和卡片来源元信息，不含「关于你」私人档案、QQ 绑定、聊天、记忆或服务凭据。完整数据备份仍使用「运行环境」的完整导出。

## 删除

删除前核对角色名与提示，选择所需范围：

- **保留聊天与记忆**：删除角色卡及入口，保留该角色已有数据。以后导入相同 ID 的卡可以继续使用保留的数据。
- **同时清除该角色数据**：删除角色卡和属于该角色的数据。请按确认页面列出的范围操作；需要备份时先完成完整导出。

至少保留一个角色；删除最后一张前，请先导入或新建另一张。角色删除后不会继续发出它尚未发送的旧回复。

## 重看新功能引导

升级后的公告中点击「看看新功能」，按箭头和高亮查看按钮。可以跳过或完成；以后到「运行环境 → 本版更新与引导」重新打开。
