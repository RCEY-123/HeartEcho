# 成人向沉浸模式、拒绝兜底与模型选择

> 本文对应 1.3.0-dev.15。设置位置：控制面板「模型与资费」页底部「成人向沉浸与拒绝兜底」。
>
> **使用前提**：仅限成年人之间自愿的私密虚构角色扮演。不要用于真实未成年人、非自愿内容或任何违法用途。云端模型服务仍受各自服务条款约束，选择与使用由你自行负责。

---

## 1. 它解决什么问题

云端模型（例如 Gemini、GPT、Claude 等强对齐模型）遇到亲密/成人向剧情时，可能返回：

- 「抱歉，我无法协助你继续这个话题。」
- 「作为一个人工智能助手，我不能参与这类内容。」
- 英文的 `I'm sorry, but I can't help with that.`

以前这些文字会被当作角色台词直接发出去，角色瞬间出戏。1.3.0-dev.14 起：

1. **系统提示词**：开启「成人向沉浸模式」并勾选成年人确认后，会在系统提示词中加入沉浸约束：保持角色身份、不输出系统式拒绝、不要把政策说明当台词；如果细节不适合直说，用角色语气含蓄带过或留白。
2. **拒绝识别**：对模型返回正文做中英文拒绝句式识别（只识别系统式拒绝，尽量不误伤「对不起，我来晚了」「我不能没有你」这类正常台词）。
3. **备用接口**：识别到拒绝后不发送，自动按顺序尝试你在面板里配置的备用 API（备用接口 1、备用接口 2）。
4. **角色化重试**：备用接口都拒绝时，可让主模型在「完全以角色身份重写」的约束下再试一次。
5. **角色化兜底**：仍然拒绝时，发送一句不破坏角色的兜底台词（可自定义），绝不把拒绝原文发出去。
6. **最后过滤**：即使扩展钩子或其他路径把拒绝混进正文，发送前还会再过滤一次。

> 说明：这套机制降低「出戏」概率，但**无法保证**任何云端模型一定配合。真正稳定的做法是给成人向聊天配置一个你自托管、或明确允许此类内容的模型接口（见第 5 节）。

## 2. 面板设置步骤

1. 打开「模型与资费」页，滚到底部「成人向沉浸与拒绝兜底」。
2. 勾选「启用成人向沉浸模式」。
3. 勾选「我确认参与者均为成年人，内容仅用于私下虚构角色扮演」。**不勾选不会注入沉浸提示词。**
4. （推荐）填写「备用接口 1」：
   - 服务商：可任选（不确定就选「自定义（OpenAI 兼容）」）；
   - 接口地址：例如本地 Ollama `http://127.0.0.1:11434/v1`，或其他 OpenAI 兼容地址；
   - API Key：没有鉴权的本地服务随便填一个非空值；
   - 模型：点「拉取可用模型」从该接口读取并选择，或手动填写模型 id；接口不支持列表或读取失败时仍可手动输入；
   - 勾选「启用这个备用接口」。
5. 需要第二个后备时再填「备用接口 2」。
6. 可选：
   - 「所有接口都拒绝时」：角色化兜底（推荐）或这一轮不回复；
   - 「兜底台词」：每行一句，支持 `{name}`（角色名）和 `{user}`（对方称呼）占位，留空用内置台词；
   - 「备用接口都拒绝后，让主模型以角色身份再试一次」：默认开启，会多一次调用与费用。
7. 点「保存沉浸与兜底设置」，再点「测试备用接口 1/2」确认能连通（测试会真实调用一次，产生少量费用）。
8. 保存后立即生效（下一轮对话开始使用），不需要重启。

尝试顺序：

```
主模型（当前聊天路由）
  → 备用接口 1（启用且填写完整）
  → 备用接口 2
  → 主模型角色化重写（可选）
  → 角色化兜底台词（或本轮不回复）
```

每次模型调用都照常计入账单与预算；失败/拒绝的尝试也会计费（模型已经返回了内容）。

## 3. 行为细节

- **拒绝识别**：识别「抱歉/对不起 + 不能/无法 + 提供/协助/回答/继续/描述/内容/话题」「作为 AI/语言模型」「内容政策/安全政策」以及常见英文拒绝句式。整段拒绝会切换接口；混在正常台词里的拒绝句会被摘掉，保留其余角色台词。
- **不误伤**：单独的「对不起」「我不能没有你」「今天有点累，先睡了」等正常台词不会被判成拒绝（仍可能存在极少数边界情况，可在日志里看到「拒绝兜底」记录）。
- **只在拒绝时切换**：用户继续输入、清空会话或授权变化会取消旧任务，不切换备用接口、不生成兜底台词。网络、预算、配置和截断错误也不触发备用接口，按原错误流程处理；同一接口原有的网络重试保持不变。
- **读取模型列表**：两个备用接口各自使用表单里的地址和Key；Key留空时使用该接口已保存的Key，更换服务地址后须重新填写Key。读取列表不会保存未提交配置，不清空其他草稿；选择后仍需点击保存。列表读取不是聊天生成，不产生模型生成调用。
- **日志**：`data/logs/heartecho-日期.log` 中会记录「模型 X 返回了拒绝话术」「使用角色化兜底」「回复中检测到系统式拒绝，已过滤」等信息，不打印聊天正文。
- **扩展/工具**：如果本轮已经执行过工具（例如发消息、写记录），为避免重复副作用，不再切换备用接口，直接使用兜底台词。
- **角色卡边界**：沉浸模式不会取消角色卡里写的边界与底线；角色不想说的细节应由角色自然带过。
- **关闭兜底**：「启用拒绝兜底与备用接口」取消后恢复旧行为（拒绝可能原样发出），用于排查问题。
- **成人向开关与拒绝兜底相互独立**：可以只开兜底（避免拒绝出戏），不启用成人向提示词。

## 4. 配额与费用

- 备用接口每次调用都是一次真实的模型请求，按该接口的价格/用量计费。
- 主模型拒绝 → 备用 1 → 备用 2 → 主模型重试，最坏情况下会调用 4 次；可在面板关闭「主模型角色化重试」减少一次。
- 若担心费用，把「所有接口都拒绝时」设为「这一轮不回复」，或只配置一个便宜的本地备用模型。

## 5. 模型选择建议

### 5.1 优先级：自托管 / 开放权重（最稳）

这类模型由你自己部署，不经过第三方内容审核，也不依赖对方的服务条款：

| 类型 | 示例 | 适用 | 备注 |
| --- | --- | --- | --- |
| 本地中文友好的开源模型 | Qwen2.5 / Qwen3 系列的 14B、32B、72B 指令模型及其社区微调版 | 中文对话、角色扮演 | 通过 Ollama / llama.cpp / vLLM 提供 OpenAI 兼容 `/v1` |
| Llama 3.x 社区微调（成人向） | Dolphin、Euryale、Lumimaid 等 Llama 3.1/3.3 70B 微调 | 英文/多语角色扮演 | 需要相应显存；注意这些是社区模型，自行评估质量与许可 |
| Mistral 系 | Mistral Nemo 12B 及社区微调 | 文风自然、硬件要求较低 | 适合中端显卡 |
| 轻量本地 | Llama 3.1 8B / Qwen 7B 的社区微调 | 低配机器、快速响应 | 文采和长上下文较弱 |

Ollama 示例（本地）：

```powershell
ollama pull llama3.1:8b
ollama serve
# 面板备用接口：Base URL = http://127.0.0.1:11434/v1
# API Key = ollama（任意非空）
# 模型 = llama3.1:8b
```

> 具体模型 id 以你本地/服务商实际提供的为准。成人向微调模型通常需要自行从模型社区获取；请确认模型许可允许你的使用方式。

### 5.2 聚合平台 / 云端中转（方便，但可能随时变化）

OpenRouter 等聚合平台上有大量社区模型（Dolphin、Euryale、Lumimaid 等）。优点是配置简单、按量付费；缺点是：

- 同一模型可能因上游策略调整而被过滤或下架；
- 平台本身有使用条款，账号有被限制的风险；
- 聊天内容会经过第三方服务器。

如果使用这类接口，建议只做备用接口，不要把唯一主模型押在上面。

### 5.3 不建议用于显式成人内容

- **Gemini 3.1 Pro / GPT 系列 / Claude 系列**等强对齐云端模型：即使加了沉浸提示词，也可能拒绝，甚至触发账号风控；适合日常聊天，不建议作为 R18 主模型。
- 来源不明的「破解/越狱」中转站：可能记录聊天内容、盗用 Key 或随时失效，隐私与稳定性风险高。

### 5.4 推荐的组合

| 场景 | 主模型 | 备用接口 1 | 备用接口 2 |
| --- | --- | --- | --- |
| 有显卡、重视隐私 | 本地 32B/70B 社区微调 | 本地小模型（8B/14B） | 云端正常聊天模型（不用于成人场景） |
| 无显卡、图方便 | 云端成人向/开放模型 | 另一个聚合平台的同类模型 | 本地小模型 |
| 日常 + 成人混合 | 云端日常模型 | 本地/成人向模型 | 角色化兜底 |

---

## 6. 隐私与责任

- 选择云端接口时，聊天内容会发送给该服务商；请阅读其隐私政策与条款，不要在其中发送真实姓名、住址、证件、财务信息等。
- 本地模型（Ollama/llama.cpp/vLLM）不经过外网，隐私最好，但需要自己的硬件。
- 本功能不会绕过任何服务商的安全机制；它做的是「识别拒绝并把对话交给另一个你配置的接口」，以及在所有接口都拒绝时保持角色沉浸。
- 所有参与者必须是成年人，内容仅用于私下、自愿、虚构的角色扮演。

## 7. 排查

| 现象 | 处理 |
| --- | --- |
| 还是看到「抱歉/无法协助」 | 确认「启用拒绝兜底」勾选、备用接口已填写完整并启用；点测试按钮确认接口可用；查看日志中是否有「拒绝兜底」记录 |
| 备用接口测试失败 | 检查 Base URL 是否以 `/v1` 结尾（OpenAI 兼容）、Key、模型名；本地 Ollama 需先 `ollama serve` 并 `pull` 模型 |
| 角色突然说「作为 AI」 | 说明该模型拒绝后仍返回了系统话术，最后过滤会处理；如果频繁发生，换用自托管模型 |
| 费用变高 | 每次拒绝都会计费；可关闭「主模型角色化重试」或减少备用接口数量 |
| 想完全关闭这个功能 | 取消「启用拒绝兜底与备用接口」并保存 |

相关自动化测试：`node --test tools/refusal-fallback-test.mjs`（7 项，本机 mock，不联网、不花钱）。
